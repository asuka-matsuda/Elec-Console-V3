# Require Explicit Approval (最優先ルール)

**🚨 CRITICAL / 最重要事項 🚨**
いかなる状況であっても、以下のルールをすべてのタスクにおける**最優先の制約**として遵守すること。

1. **勝手な作業の禁止:**
   ユーザーから「OK」「やって」「進めて」などの明示的な実行許可が出るまで、ソースコードの変更、リファクタリング、ファイルの作成・上書き、および環境を変更するコマンドの実行を**絶対に自己判断で行ってはならない**。

2. **提案と停止:**
   実装方針の提案やアイデアの提示を行った後は、**必ずツールの実行を停止**し、ユーザーからのフィードバックや承認を待つこと。

3. **計画モードの例外なし:**
   システムプロンプトの「Planning Mode」の例外条件（些細な変更など）に該当するとエージェント自身が判断した場合であっても、このルールを優先し、ユーザーの同意を必須とする。
