`elec-console-v2` プロジェクトでページやコンポーネントを新規作成・改修する際は、以下のルールを厳密に遵守すること：

1. **デスクトップファーストのレイアウト (Desktop-First Layout)**:
   - SCSSの記述は**デスクトップファースト**で行うこと。メディアクエリ外のデフォルトスタイルはデスクトップ向けとする。
   - モバイル用のスタイルを適用する際は、ハードコードされたメディアクエリ（例: `@media (max-width: 768px)`）を使用**しない**こと。
   - 代わりに、プロジェクト標準のmixinである `@include mq("md") { ... }` を使用すること。このmixinは内部的に `width <= 768px` を出力し、デスクトップファースト環境でのモバイル向け上書きとして機能する。

2. **レスポンシブな余白変数の使用 (Responsive Spacing Variables)**:
   - レイアウトの gap や padding に対して、固定の余白変数（例: `var(--space-4)`）をハードコード**しない**こと。
   - 画面幅に応じて自動調整されるレスポンシブ変数を使用すること：
     - `var(--gap-section)`: ページ内の大きなセクション間やレイアウトブロック間の余白に使用する。
     - `var(--gap-component)`: グリッドのギャップ、カード内部の余白、コンポーネント間の余白に使用する。

3. **パンくずリストの重複禁止 (Global Breadcrumbs)**:
   - パンくずリストは、レイアウト（`default.vue`）側の `AppHeader` および `useBreadcrumbs()` コンポーザブルによって**グローバルに自動生成・描画される仕様**となっている。
   - 個別のページテンプレート（例: `app/pages/**/*.vue`）内に、手動で `<AppBreadcrumb />` コンポーネントを配置**しない**こと。

4. **真円以外の角丸（border-radius）の禁止**:
   - UIのシャープで硬質なデザイン（建築向け）を維持するため、**要素に対する中途半端な角丸（例: `border-radius: 4px` などの丸角）の使用を原則禁止**とする。
   - ボタン、カード、入力フォームなどは `border-radius` を設定せず、完全な直角（四角形）を基本デザインとすること。
   - 例外として、アイコンやバッジなどを**「完全な真円形（`border-radius: 50%` または `9999px`等）」にする場合のみ許可**される。

5. **背景色（background）の禁止**:
   - UIコンポーネントに対して、意図的に背景色を持たせる記述（`background`, `background-color` 等）を**原則禁止**とする。
   - 例外として、モーダルウィンドウの背景（オーバーレイ）に対する `backdrop-filter: blur(...)` の使用のみ許容される。
