# 一気通貫の実装ルール (Vertical Slice Development)

AI駆動開発（AI-Driven Development）におけるバグと二度手間を防ぐため、以下の実装アプローチを厳守すること。

1. **モック先行の禁止**:
   フロントエンドのUIや状態管理（LocalStorage, メモリ上のダミーデータ等）だけで新機能のモックを作ることを禁止する。

2. **一気通貫での実装 (Vertical Slice)**:
   新機能を追加する際は、必ず以下の工程を1つのセットとして同時に実装すること。
   - バックエンドのデータベース定義・保存ロジックの作成
   - サーバーAPI（GET/POST/PUT/DELETE等）の実装
   - フロントエンドからの非同期通信連携と状態管理の確立
   - UIの構築

3. **理由（コンテキスト）**:
   フロント・バックエンドを切り離して実装すると、AIのコンテキストが分断され、タブ間の同期ミスやリレーションの不整合など「ハリボテ」に起因する負債が発生しやすくなる。AIの「システム全体を同時に把握できる」という強みを最大限活かすため、常にフルスタックで実装を貫通させること。
