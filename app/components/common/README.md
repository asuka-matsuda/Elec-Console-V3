# 共通 UI コンポーネント（LOCKED / 凍結済み）

このディレクトリ（`app/components/common`）配下のコンポーネント群および `app/types/components.ts` は、Vercel Geist デザインシステム準拠の設計、直角規約（`border-radius: 0`）、アクセシビリティ方針、単一責任原則を満たし、品質検証（TypeScript / ESLint / Stylelint / Vitest 全件パス）を経て**完全凍結（ロック）**されています。

---

## 🔒 変更禁止およびハック禁止原則

1. **原則変更禁止（ロック）**
   - 共通コンポーネント自体の独断での改修・プロップ追加・デザイン変更・薄いラッパーの作成を固く禁止します。

2. **呼び出し側（Consumer）でのハック・迂回工作の厳禁**
   - 「共通コンポーネントがロックされているから」という理由で、**呼び出し側（`/pages` や機能別コンポーネント）で無理な CSS 上書き（`!important`、ネガティブマージン、深層セレクタハック）、ラッパー要素の乱立、インラインでのオレオレ再実装等のハック修正を行うことは厳禁**です。
   - 共通コンポーネント自体のプロップ不足やスタイル調整、機能拡張が真に必要だと判断した場合は、**決して呼び出し側で誤魔化さず、「〇〇コンポーネントの△△の修正が必要です」とユーザーに明示して指示・許可を仰いでください**。

## 📦 凍結コンポーネント一覧（全 30 コンポーネント）

### Atoms (17)
- `Avatar`: アバター（幾何学的真円・イニシャルフォールバック）
- `Badge`: メタデータバッジ（短文ステータス・1行1個）
- `Banner`: 画面全幅のシステム重要告知
- `Button`: 多態ボタン（Primary/Secondary/Tertiary/Danger/Warning・NuxtLink自動解決）
- `Checkbox`: マルチセレクト・規約同意（二値・不確定 indeterminate）
- `Gauge`: 円形比率・クォータ・ヘルスメーター
- `Icon`: 共通 Lucide アイコンラッパー
- `Input`: 1行テキスト/数値入力（`clearable` インライン消去機能統合済み）
- `Progress`: 水平プログレスバー（確定タスク進捗）
- `Radio`: 排他的単一選択ラジオボタン
- `Select`: Popover API ベースのドロップダウンセレクト（上下自動反転）
- `Skeleton`: CLS防止プレースホルダー（子要素ラッピング＆スタンドアロン）
- `Spinner`: 12本放射状バーのローディングインジケーター
- `Switch`: 2〜3項目の排他的セグメントスイッチ
- `Textarea`: 複数行テキスト入力（autoResize / field-sizing 対応）
- `Toggle`: 単一機能の即時 ON/OFF スイッチ
- `Tooltip`: 遅延表示・Escape対応ツールチップ（Teleport浮遊表示）

### Molecules (11)
- `Breadcrumbs`: 階層ナビゲーション（現在地コンソールカーソル点滅）
- `Calendar`: 日付・期間選択カレンダー（プリセット対応）
- `Collapse`: 折りたたみ・展開アコーディオン項目（CSS Grid アニメーション）
- `CollapseGroup`: 複数 Collapse のアコーディオン排他制御・包括コンテナ
- `Dropzone`: ファイルドラッグ＆ドロップ・アップロード（プレビュー・解除・直角破線）
- `EmptyState`: 6系統バリアントの空状態案内
- `Menu`: クリック展開ドロップダウンメニュー（ウィンドウ境界自動反転・キーボード操作）
- `Note`: インライン通知（永続・4大バリアント・単一CTA）
- `Table`: ネイティブ table/colgroup・Skeleton/EmptyState/ソート統合テーブル
- `Tabs`: ビュー切替タブ（下線アクセントグラデーション自己完結）
- `Toast`: インラインアクション対応トーストスタック

### Organisms (2)
- `GlobalNav`: ドロワーサイドバーナビゲーション
- `Modal`: ネイティブ dialog ベースの直角モーダル
